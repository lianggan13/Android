# 💻 工作技能

## 🧩 C# 基础

- 泛型（协变/逆变、约束、泛型集合与算法抽象）
- LINQ（查询表达式/方法语法、延迟执行、分组与联接、Queryable/Enumerable）
- 异步/并发（async/await、Task/ValueTask、CancellationToken、同步上下文）
- 多线程（Thread/ThreadPool、TPL、并行 LINQ、并发容器、锁与无锁编程）
- 任务（Task 组合、超时与重试、异常聚合与传播）
- 反射/表达式树（元数据、动态加载、特性、Emit/Expression）
- 委托/事件（多播委托、事件模式、回调与解耦）

## 🧠 设计思想

- OOP 面向对象（抽象/封装/继承/多态，SOLID 原则）
- AOP 面向切面（日志、监控、鉴权、事务拦截与横切关注点）
- DI 依赖注入（接口隔离、可替换性、生命周期管理、组合根）
- MVVM 模式（命令/绑定、状态管理、可测试性、组件化）
- 设计模式（工厂/策略/观察者/装饰/适配/代理/模板/单例/仓储等）
